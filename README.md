# Vantage Cue

Современный демонстрационный магазин бильярдных киев и аксессуаров. Проект создан как самостоятельный фронтенд: каталог, фильтры, карточки товаров, корзина и оформление заказа работают прямо в браузере.

## Демо

После публикации сайт доступен по адресу: **https://delivery12335.github.io/vantage-cue-demo/**

## Что реализовано

- каталог с фильтрами, сортировкой и быстрыми категориями;
- отдельные страницы товаров и связанные рекомендации;
- поиск по каталогу;
- корзина с сохранением после перезагрузки страницы;
- оформление заказа с выбором способа получения;
- профиль, история заказов и локальные настройки студии;
- адаптивная версия для телефона, планшета и компьютера.

Данные демонстрационного магазина сохраняются в `localStorage` браузера. Никакой сервер или база данных для просмотра демо не требуются.

## Технологии

- Next.js 16 и React 19
- TypeScript
- CSS
- Framer Motion
- Lucide Icons

## Локальный запуск

```bash
npm install
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000).

Проверки кода:

```bash
npx tsc --noEmit --incremental false
npm run lint
```

## Публикация

При каждом пуше в ветку `main` GitHub Actions собирает проект и публикует его на GitHub Pages.

После первого пуша в репозитории откройте **Settings → Pages** и выберите источник **GitHub Actions**, если GitHub не включил его автоматически.

## Авторизация Supabase (необязательно)

Для демонстрации сайт работает и без Supabase. Если нужна настоящая авторизация, создайте `.env.local` на основе `.env.example` и добавьте URL проекта и публичный ключ Supabase. Подробности — в [AUTH-SETUP.md](AUTH-SETUP.md).
